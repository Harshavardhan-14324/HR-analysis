# HR-analysis Project

## Project Objectives
To analyze HR data and develop an interactive Power BI dashboard that provides actionable insights into employee demographics, attrition, performance, hiring trends, training costs, and satisfaction. The goal is to enable data-driven HR decision-making, improve workforce management, and enhance organizational performance through effective data visualization.

## Final Conclusion
The HR Analytics Dashboard successfully transforms raw HR data into meaningful insights through data cleaning, analysis, and visualization. By leveraging Excel, Python, MySQL, and Power BI, the dashboard provides a comprehensive view of workforce metrics such as employee distribution, attrition, hiring trends, performance, satisfaction, age, gender, and training costs. These insights enable HR teams to make informed, data-driven decisions, improve employee retention, optimize workforce planning, and support overall organizational growth.
