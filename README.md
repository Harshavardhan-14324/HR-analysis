# HR-analysis Project

## Project Objectives
To analyze HR data and develop an interactive Power BI dashboard that provides actionable insights into employee demographics, attrition, performance, hiring trends, training costs, and satisfaction. The goal is to enable data-driven HR decision-making, improve workforce management, and enhance organizational performance through effective data visualization.

## Process
### 1.Data Collection
-> Collected the HR dataset from a reliable source.
### 2.Data Cleaning (Excel & Python)
-> Removed duplicate records.
-> Handled missing values.
-> Standardized date formats.
-> Renamed columns.
-> Corrected text formatting and data inconsistencies.
-> Created derived columns such as Age and Full Name.
### 3.Data Storage (MySQL)
-> Imported the cleaned dataset into MySQL.
-> Executed SQL queries to analyze employee data and validate results.
### 4.Data Visualization (Power BI)
-> Connected Power BI to the MySQL database.
-> Built relationships and created DAX measures.
-> Designed interactive dashboards with KPIs, charts, and slicers.
### 5. Analysis & Insights
-> Analyzed employee distribution, attrition, performance, satisfaction, hiring trends, age groups, gender distribution, and training costs.
-> Identified key HR trends to support data-driven decision-making.
### 6.Dashboard Development
-> Created a professional, interactive HR Analytics Dashboard with filters, KPI cards, and multiple visualizations for easy business reporting.

## Final Conclusion
The HR Analytics Dashboard successfully transforms raw HR data into meaningful insights through data cleaning, analysis, and visualization. By leveraging Excel, Python, MySQL, and Power BI, the dashboard provides a comprehensive view of workforce metrics such as employee distribution, attrition, hiring trends, performance, satisfaction, age, gender, and training costs. These insights enable HR teams to make informed, data-driven decisions, improve employee retention, optimize workforce planning, and support overall organizational growth.
